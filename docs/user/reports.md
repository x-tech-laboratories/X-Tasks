# Reports

The **Reports** view is a page of cards you choose and arrange. Add cards, move them up or down, or remove them from
each card's menu. Most cards look back a set number of days, and any card can be limited to tasks holding certain tags
— plain or [rule tags](tags-and-filters.html#rule-tags).

| Card                | Shows                                                                                    |
| :------------------ | :--------------------------------------------------------------------------------------- |
| **Routine streaks** | Each repeating task's current streak and recent done and missed occurrences; subtasks can be left out |
| **Ticks per day**   | A calendar of how many tasks you completed each day                                      |
| **Ticks per week**  | Completed tasks per week                                                                 |
| **Ticks by tag**    | Completed tasks split by the tags of a filter group, in the tags' colours                |
| **Task map**        | A graph of tasks and the relationships between them, with done tasks shown or hidden     |

Deleting completed tasks with **Clear completed** also takes their ticks out of the reports.
