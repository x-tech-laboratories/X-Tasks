# Settings reference
{: .no_toc }

Every setting, in the order the Settings page shows them. Defaults are in **bold**.

1. TOC
{:toc}

## General

| Setting                       | What it does                                                                                 |
| :---------------------------- | :------------------------------------------------------------------------------------------- |
| Theme                         | **System**, light or dark. Browsers always follow the system.                                 |
| Tint task rows by tag         | Shades each row with its first coloured tag. **Off**.                                        |
| Streak dots on task rows      | Shows routines' last week of done and missed occurrences beside the title.                    |
| Open on launch                | The view the app starts on: **the last one shown**, or a fixed view.                          |

## Tasks

| Setting                                   | What it does                                                                     |
| :---------------------------------------- | :------------------------------------------------------------------------------- |
| Syntax                                    | How the bar reads a new task's tags, dates and repeats. **Todoist**.             |
| Subtasks start with their parent's tags   | Copies the parent's tags onto a new subtask. **Off**.                            |
| Collapse completed branches               | Folds a finished task's subtasks once they are all done. **Off**.                |
| Ask before clearing completed tasks       | **On**.                                                                          |
| Clear My Day each day                     | **On**.                                                                          |
| Add due tasks to My Day                   | **Off**.                                                                         |
| Remove completed tasks from My Day        | **On**.                                                                          |
| Remove rescheduled tasks from My Day      | **On**.                                                                          |
| Task details                              | Reorder or hide the sections of a task's details.                                |
| Relationships                             | Name each relationship both ways and choose which task depends on the other.     |

## Dates

| Setting                  | What it does                                                                               |
| :----------------------- | :----------------------------------------------------------------------------------------- |
| Task date                | The date tasks are shown, sorted, filtered, rescheduled and put in My Day by: **due** or start. |
| Overdue repeating tasks  | Each day, leave them (**default**), move them to today, or move them to their next date.    |
| Repeats in Upcoming      | Days ahead Upcoming lists later repeat dates. **7**.                                       |
| Reschedule               | The quick dates offered by Reschedule: a number of days, or the next date of a repeat rule. |
| Durations                | The lengths offered by the Duration list in a task's details.                              |

## Views

| Setting                    | What it does                                                                             |
| :------------------------- | :--------------------------------------------------------------------------------------- |
| Default layout             | **List**, table, board, calendar or Gantt.                                               |
| Layout per view            | **Remembered**, saved by hand, or the same everywhere.                                   |
| Scroll the table sideways  | **Off**.                                                                                 |
| Default grouping           | **None**, date, or a filter group.                                                       |
| Grouping per view          | **Remembered**, saved by hand, or the same everywhere.                                   |
| Time slots / Time labels   | The calendar's week and day views: **30** minute rows, a time every **60** minutes.      |

## Tags and search

| Setting                    | What it does                                                                              |
| :------------------------- | :---------------------------------------------------------------------------------------- |
| New filter group           | Adds a group of plain tags or rule tags.                                                  |
| Tag selection              | One tag in all, **one from each group**, or any number.                                   |
| Match tasks with           | **Every selected tag**, or any of them.                                                   |
| Parent tags show           | **Tasks of the tags inside it too**, or only its own.                                     |
| Show empty tags            | **On**. When off, the sidebar hides tags no task has.                                     |
| Ask before deleting a tag  | **On**.                                                                                   |
| Tag colours                | The palette offered when colouring a tag.                                                 |
| Search in                  | **The view on screen**, or every task.                                                    |
| Syntax                     | How the bar reads a search. **Todoist**.                                                  |

## Data

| Setting            | What it does                                                                                         |
| :----------------- | :--------------------------------------------------------------------------------------------------- |
| Database           | Shows where your tasks are stored.                                                                   |
| Backups            | Back up now, back up daily, how many daily backups to keep, and the list of backups.                 |
| History            | Delete old history (**off**) and how many days to keep.                                              |
| Sync               | Server address, access token, and whose tasks to keep. See [Sync](sync-and-backups.html#sync).       |
| MCP server         | Desktop only. Lets AI assistants on this computer work with your tasks. See [AI assistants](ai-assistants.html). |
