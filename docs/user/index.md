# User guide

This part of the documentation is for people **using** X-Tasks: on the desktop, in a browser or on Android. It needs
no programming knowledge. If you want to build, host or change X-Tasks, see the [developer guide](../developer/).

Start with [Getting started](getting-started.html) to install the app, then read [Core concepts](core-concepts.html):
the rest of X-Tasks makes most sense once you know about the one big list, nesting, filter groups and rule tags.
